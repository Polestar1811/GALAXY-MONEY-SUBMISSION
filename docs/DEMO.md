# InvestLens by Galaxy — 演示录屏与脚本

## 录屏

`docs/demo/investlens-demo.webm` 由 `npm run record:demo` 生成：Playwright 在本机 Chrome 中**实际操作产品**（真实扶摇数据 + 真实大模型），全程录制，没有剪辑、加速或预设内容；画面中的等待时间就是真实耗时。生成条件：已配置真实凭证并完成 `npm run build`。

> 录屏是否已生成、时长与生成时间，以 [ITERATION_3_REPORT.md](ITERATION_3_REPORT.md)「交付状态」为准。

## 演示脚本（约 150 秒，与录屏顺序一致）

| 时间 | 画面 | 讲解要点 |
|---|---|---|
| 0–20s | 首页 Hero → 「三个阶段」→ 象牙色「两种投资者视角」研究舞台 | InvestLens by Galaxy：先理解你，再理解市场。同一组真实行情（左），两位虚构投资者的研究重点不同（右），事实层指纹一致。 |
| 20–45s | Genesis：逐题回答（大额支出、1 年以内、考虑小幅增加、5–10%、很可能需要大部分、暂无储备），跳过收入题，勾选确认 | 每次只问一个问题，可跳过、可返回；区分「愿意承受」与「能够承受」；右侧实时画像；默认不保存。 |
| 45–95s | 研究工作台：真实行情徽标、「最新交易日 … 收盘」、前复权日线 → 输入问题「我想长期研究沪深300 ETF，目前有哪些最值得关注的风险和证据？」→ 阶段进度、并行工具调用、模型流式进度 → 结论、证据编号、发送给模型的画像字段 | 数据来自同花顺扶摇；模型只解释，事实只来自数据；每条结论带 Evidence ID，点击可跳到证据区；校验通过标记。 |
| 95–130s | 切换到画像 B → 事实指纹「与画像 A 一致」→ 模块重排 → 并排对比 | 客观数字不变，只有研究顺序、个人相关度和解释改变；客观严重程度对两人相同。 |
| 130–150s | 画像与隐私页 | 用户可以看到 AI 知道什么、修改 / 撤回任一字段、查看影响了哪些规则、一键清除。产品不给买卖指令，不以交易频率为目标。 |

## 现场演示的备用路径

- 模型暂时不可用：研究页显示明确错误（例如「模型服务超时」），不会出现替代结论；规则研究视图与真实行情仍可用。
- 扶摇暂时不可用：研究页显示「研究服务暂时不可用」及错误码，不会回退为演示数据。
- 没有任何凭证：全站显示「演示数据 · 非实时」，AI 研究面板显示「未配置大模型」，可用于离线讲解界面与个性化逻辑。
