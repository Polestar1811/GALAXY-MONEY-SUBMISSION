## 4. 真实验收中发现并修复的问题

| 问题（第 1 次真实运行） | 影响 | 修复 | 回归测试 |
|---|---|---|---|
| 用户说「没有别的储备了」，模型记为「不便透露」 | 把事实误记为拒答，承受能力被低估为「未知」 | 「不便透露」必须伴随明确的拒答表述；提示词补充说明 | ✅ |
| 用户说「50 万左右」，模型归为 5–20 万 | 资金区间错误，并传播到人格叙述 | 用户给出明确金额时，按数字确定区间 | ✅ |
| 同一矛盾被反复以不同措辞报告（6 条） | 「值得留意」列表冗余 | 告知模型已记录的矛盾；只保留最近 3 条 | ✅ |
| 组合页「账面最多曾减少约 −518 元」 | 双重否定 | 金额取绝对值 | 视觉检查 |

第 2 次真实运行确认：储备记为「不到 3 个月」、50 万归入 20–100 万、矛盾不再重复。

## 4.1 质量收口（2026-10-23）

| 项 | 做法 | 结果 |
|---|---|---|
| AI 转述用户数字不准确 | 研究伙伴的回应、矛盾说明与追问中的数字（含「一万」「三成」等中文数字）必须出现在用户回答、已知信息或访谈问题中，否则不展示该句 / 不采用该追问；人格与路径文本中带金额单位的数字同样核验 | 单元回归 ✅；真实模型复测：回应 17/17、16/16 均保留，矛盾说明中的数字与原话一致 |
| 访谈刷新后丢失 | 「在本设备临时保存访谈进度」开关，**默认关闭**；开启后写入 `galaxy.interview.v2.draft`，24 小时自动删除，关闭开关立即删除；刷新后提示「继续 / 删除」，不自动恢复；画像确认或一键清除时删除 | E2E ✅（默认不保存、开启后可恢复、关闭即删除） |
| 组合回测独立复核 | `tests/live/backtest-audit.live.ts`：直接请求扶摇原始日线，用独立的「份额法」重算，与产品实现在同一数据上比较 | 8 种配置（3 组合 + 基准 × 月度 / 不再平衡）累计收益、年化、最大回撤、波动最大差异 1.3×10⁻¹⁵；交易日数与再平衡次数（37 次）一致 |
| 复权 | 扶摇文档注明日线为前复权；响应中的 `adjust` 字段为空；最新收盘价与快照价一致（收盘后） | 无法用未复权序列独立验证分红处理，依赖数据源说明（已在假设中注明） |
| 当日未收盘 K 线（复核中发现） | 交易时段内扶摇日线包含当天未完成的 K 线：在数据层剔除（北京时间 15:05 前）——回测、区间涨跌、回撤、波动、图表与「日线截至」都只用已完成的 K 线；InvestLens 不再把盘中价标为「收盘」 | 单元回归 ✅；回测结束日为最近完整交易日 |
| 费用 | 产品不计交易佣金与价差；按换手率估算：B / C 组合 3 年累计换手 78% / 86%，按单边万三估算成本约 0.024% / 0.026% | 对结论影响可忽略，已在假设中说明 |

记录：`docs/live-verification/backtest-audit-2026-10-23.json`、`v2-live-2026-10-23.json`。

回归：单元 **181 / 181**，E2E **53 / 53**，V2 真实验证 2 / 2。

## 5. 未覆盖 / 已知限制
