## 1. P0 · 真实 AI 研究速度

### 1.1 做了什么

1. **阶段耗时拆分**：每次研究返回 `timings`（数据获取、研究规划、校验、个性化、模型生成、护栏校验、总计、首个事件），在研究面板的「研究计划与校验明细」中展示。
2. **并行**：研究规划（LLM）与数据获取不再串行；数据侧快照、日线、资料 / 估值 / 资讯并行请求，Provider 缓存「进行中的请求」，同一资源只访问一次上游。研究页加载时即预热数据，用户提问时通常命中缓存。
3. **流式真实进度**：模型使用流式响应，界面每秒更新「已接收 N 字 / 正在输出」，以及真实的已用时间；推理内容只计数、从不展示；没有任何伪造的百分比。
4. **长尾治理**（真实运行中发现）：扶摇日线实测 2.3–12.2 秒 → 单独 30 秒超时；快照通常 0.4 秒但偶有 4–10 秒以上 → 首次 6 秒 + 重试 15 秒；瞬时错误退避重试一次。
5. **模型对比**：基于账号实际可用的模型（`GET /models`：`deepseek-flash`、`deepseek-v4-pro`），在同一问题、同一事实快照、画像 A / B 下比较 5 种配置。思考模式参数来自 DeepSeek 官方文档，通过供应商无关的 `LLM_EXTRA_BODY` 配置，没有写死在代码里。

### 1.2 实测结果（`docs/live-verification/model-benchmark-2026-10-22.json`）

数据已预取（同一快照），以下时间主要是模型时间；冷启动数据获取另测为 2.5–8.0 秒，且与规划并行。

| v4-pro · 思考 low | 53.7s | 53.3s | 13–16s | 38–40s | 100% | 0 | 0 | 0 | ~3.4k / 4.4–5.0k | ¥0.076–0.082 |
| flash · 思考 high | 23.2s | 19.2s | 3.9–4.9s | 14–19s | 100% | 0 | 0 | 0 | ~3.5k / 3.7–4.8k | ¥0.018–0.023 |

- 首个可见进度：所有配置均为 0.1–0.4 秒（阶段与工具事件立即流式推送）。
- 成本按官方价格（空闲时段，输入按缓存未命中计）：flash 输入 1 元 / 输出 4 元每百万 tokens；v4-pro 输入 4.5 元 / 输出 13.5 元。
- 第一次基准中 flash（low / 关闭思考）的画像 B 各有 1 次失败，诊断为**我们的输出 schema 过严**（信息缺口 7 条 > 上限 6 条），不是证据或数值问题；修复后重跑全部通过。两次记录都保留在 `docs/live-verification/`。

### 1.3 默认模型决策

`deepseek-flash` + 关闭思考满足所有门槛：证据完整性、数值一致性、合规检查与 v4-pro 相同（自动指标），人工阅读结论的具体性与依据相当；之后又在产品价值实验中连续 6 次真实运行全部通过。修复 schema 后的累计记录：10 / 10 次完成。

因此设为默认：**端到端 A / B 研究从第二迭代的约 140–150 秒（两次）降到约 13 秒；浏览器真实流程（含页面加载、数据获取与研究）两次实测 9.3 秒与 21.7 秒**（`verify:live-ui`，差异主要来自扶摇冷启动延迟），成本约为原来的 1 / 10。

保留切换能力：`LLM_MODEL=deepseek-v4-pro` 或去掉 `LLM_EXTRA_BODY` 即恢复推理模式。限制：自动指标无法完全衡量推理深度，样本较小（见 §7）。

## 3. P0 · 差异化表达

首页重构为四个编号段落：

1. **Hero**：UNDERSTAND YOU / THEN THE MARKET.（先理解你，再理解市场。）+ 两个入口：「体验两种投资者视角（无需填写）」「建立我的画像」；底部状态条按**运行时**配置显示真实 / 演示数据与模型。
2. **01 · 三个阶段**：Understand You → Understand the Market → Research for You，各自直达对应页面。
3. **02 · Two investors. One market.**（象牙反白区）：两张虚构画像卡一键打开研究工作台；研究舞台在真实模式下请求真实 A / B 研究，展示「左侧事实相同（指纹一致）/ 右侧研究重点不同」。
4. **03 · Your data. Your decision.**：看见、修改 / 跳过 / 撤回、追溯每次研究使用的画像字段、决定权在你；明确「不追求让你交易更多」。
5. **04 · Trust is earned. Not declared.**：真实数据、证据编号、数值核验、合规边界。

## 4. P0 · 研究工作流打磨

- 公网用户的 10 步流程在 E2E 与真实录屏中完整走通（首页 → 选择画像 / 建档 → 工作台 → 真实行情与来源 → 自然语言提问 → 真实 Agent 步骤 → 证据结论 → 切换 A/B → 事实一致 → 追问 / 修改画像）。
- 模型不可用：显示明确错误与错误码，不生成替代结论；无凭证时全站标注演示数据，AI 面板显示「未配置」。
- **指标对象核实**：扶摇字段 `track_index_pe_ttm_five_year_percentile` 的文档描述为「跟踪指数 PE TTM 五年分位」，界面名称「跟踪指数 PE 分位（5 年）」准确描述的是**跟踪指数**而非 ETF；回撤、波动、收益基于 ETF 自身前复权日线计算。
- 时点：快照接口时间戳是响应时间（第二迭代实测），界面显示「最新交易日 … 收盘 · 快照获取于 …」，不会把过期数据标成实时。

## 6. 需要用户操作（阻塞项）

1. **轮换密钥（发布前必须）**：扶摇与 DeepSeek 的 Key 曾出现在对话中。请在扶摇「API Key 管理」与 DeepSeek 平台重新签发，旧 Key 作废；公网部署使用新 Key。
2. **GitHub**：本机未安装 `gh`。请创建空仓库（建议先设为 private，确认数据展示许可后再公开），然后执行：
   - `git remote add origin https://github.com/<你的账号>/investlens.git`
   - `git push -u origin main`
   公开仓库属于对外发布，需要你明确授权。
3. **Vercel**：需要你的账号登录（`npx vercel login`）或在 Vercel 网站导入 GitHub 仓库；配置环境变量（使用轮换后的新 Key）；部署后告诉我地址，我会用 `PLAYWRIGHT_BASE_URL=<地址> npm run verify:live-ui` 做公网真实验证。**不会修改任何生产 DNS 或 Galaxy 现有域名 / Arena 路由**，先使用 Vercel 临时域名。
4. **Galaxy 资产**：确认上述 Galaxy 目录是正确来源，且符号与主视觉允许在 InvestLens 中复用。

## 7. 尚未解决的问题与风险

| 风险 | 说明 |
|---|---|
| 公网未验证 | 部署后的网络、冷启动、流式兼容性、扶摇对云端 IP 的访问等尚未验证 |
| 快速模型的推理深度 | 关闭思考后，复杂问题的推理深度可能下降；当前自动指标与人工阅读未发现差异，但样本小（10 次） |
| 扶摇长尾延迟 | 已加重试，但上游持续缓慢时一次研究可能需要 20 秒以上才能取到数据 |
| 单进程内存缓存 | 事实快照与请求缓存在单实例内存中；Serverless 多实例下 A/B 复用快照可能失效（会重新获取，事实可能因行情更新而不同，指纹会如实显示） |
| 资讯分支 | 510300.SH 资讯接口返回 0 篇，真实「资讯 + 行情」结合未被验证 |
| 自动化验证代替真实用户 | 产品价值实验是自动指标，不是用户研究 |
| 数据许可 | 公开仓库与截图中的扶摇数据展示需确认许可 |
