## 由测试或人工检查发现的 AI 初版缺陷

| # | 缺陷 | 发现方式 | 修复 |
|---|---|---|---|
| 1 | 情景模拟把年化回报按 r/12 月复利，终值高估 | 单元测试失败（期望 `P·1.05^10`） | 使用等效月利率 |
| 2 | Genesis 选择后 220ms 内点「跳过」会覆盖答案并跳两步 | E2E 全链路测试失败，读取页面快照定位 | 过渡锁 + `stepRef`，动画期间禁用按钮 |
| 3 | 移动端 Dashboard 面板横向溢出 | **人工看截图发现**；原自动化检查因 `body{overflow-x:hidden}` 漏检 | `Panel` 加 `min-w-0`；测试改为检查 `body.scrollWidth`，并先在未修复构建上验证测试确实失败 |
| 4 | 价格轴刻度不均匀 | 人工看截图 | 定义域按 0.05 / 0.1 取整 |
| 5 | 目标卡「12 个月 · 可能用款」标签溢出卡片 | 人工看截图 | 靠近末端时右对齐并隐藏末端标签 |
| 6 | 研究页同时出现两个画像切换 | 人工看截图 | 研究路由隐藏顶栏切换 |
| 7 | 右侧栏 sticky 但高于视口，下半部分长时间不可达 | 人工看截图 | 取消 sticky |
| 8 | 1 年期情景曲线只有 2 个点 | 人工看截图 | 3 年以内按月取点 |
| 9 | 文案中硬编码了画像 A 的数值（如「5–10%」），用户自己的画像会显示错误信息 | 编写过程中自查 | 改为 `{p:lossCapacity}` 等占位符从画像取值，并加测试确保无残留占位符 |
| 10 | E2E 选择器「跳过」同时匹配了预览中的「已跳过」 | Playwright strict 模式报错 | 使用 `exact: true` |

## 人工确认过的合规与诚实性要点

- 所有合成数值都带「演示 / 计算 / 待核验 / 未知」状态；`asOf` 为 `null` 并显示「合成快照 · 无真实时点」；`source.url` 为 `null`（不伪造出处）。
- 图表横轴使用「T-偏移」而不是伪造的真实日期。
- 不支持的标的、无权限、服务错误都显示明确状态，不生成任何数字。
- 无买卖建议、目标价或收益承诺；情景模拟器标注「假设，不是预测」并公开公式。
- 没有使用 OKX / Binance 的标志、图片或页面素材；品牌标识为自绘 SVG。
- 未写入任何 API Key；`.env.example` 只列出第二迭代需要的服务端变量名。

## 未覆盖 / 需要后续人工验证

- 未在真实 iOS / Android 设备上测试（只用 Chrome 视口模拟）。
- 未使用屏幕阅读器做完整走查。
- 未在 Safari / Firefox 中测试。

## 第二迭代最终验收（真实凭证，2026-10-22）

用户在对话中提供了扶摇与 DeepSeek 的 API Key。AI 将其写入 `.env.local`（已被 `.gitignore` 忽略），之后的所有输出、日志与验证记录都不包含密钥（脚本写入前会检查；最终检查 `docs/live-verification/` 中不含 `sk-`）。建议用户在验收后轮换这两个密钥，因为它们曾出现在对话中。

| 步骤 | AI 的做法 | 验证 |
|---|---|---|
| 选择模型 | 不猜模型名，先调用 `GET /models`：账号只有 `deepseek-flash`、`deepseek-v4-pro`；分别做小规模 JSON 调用，发现两者都是推理模型，flash 在小额度下正文为空 | 选择 v4-pro，并调大 token 与超时 |
| 真实接口验证 | `npm run verify:live`：扶摇 5 个接口、真实 LLM 画像 A / B | 3 / 3 通过 |
| 独立复核数值 | 不复用产品代码，在 PowerShell 中直接请求原始日线并重算收益、回撤、成交额 | 与产品输出完全一致 |
| 审计 LLM 输出 | 逐条检查结论、证据 ID、数值、风险等级与画像字段 | 发现千分位与日期两处误判（护栏过严），修复 |
| 时间语义 | 连续两次请求快照与资料接口，对比时间戳 | 发现快照与资料的 `timestamp` 是响应时间，修复时点标注 |
| 真实 UI | 新增 `npm run verify:live-ui`，在浏览器中输入问题完成研究并截图 | **人工看截图发现 A / B 指纹「不一致」**（自动化验证未覆盖），定位为并发请求重复访问上游 + 时间戳抖动，修复并新增断言 |
| 回归 | tsc、单元 85、构建、E2E 38、真实验证 4 项 | 全部通过 |

人工检查的价值：A / B「不一致」只在真实数据、页面并发加载时出现，单元测试、Mock E2E 与接口级真实验证都通过了，是通过查看真实 UI 截图发现的。

## 关键过程

| 步骤 | AI 的做法 | 验证 |
