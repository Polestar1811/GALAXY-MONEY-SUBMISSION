## 3. 第三迭代中由测试或真实运行发现并修复的缺陷

| 缺陷 | 发现方式 | 修复 |
|---|---|---|
| 扶摇历史日线耗时 2.3–12.2 秒波动，统一 10 秒超时间歇失败 | 真实基准运行失败 + 实测延迟 | 日线单独 30 秒超时；缓存 10 分钟 |
| 扶摇快照通常 0.4 秒，但偶有 4–10 秒以上长尾 | 真实实验运行失败 + 实测 | 首次 6 秒超时 + 15 秒重试一次；瞬时错误退避重试 |
| deepseek-flash 返回 7 条信息缺口（上限 6），整份合规回答被拒绝 | 真实基准降级 + 诊断脚本 | 列表超长截断而非拒绝；新增回归测试 |
| 首页服务端组件调用了 `"use client"` 模块中的函数（构建通过、运行时报错） | E2E | 映射函数移到共享模块 |
| 首页在构建时读取配置，可能把演示环境标成「真实数据」 | 截图人工检查 | 首页改为运行时渲染 |
| 并行化后阶段完成顺序变化 | 单元测试 | 测试改为验证并行语义 |
| 基准记录缺少 Agent 自身错误原因 | 诊断过程 | 记录 `stage/code/message` |
| 思考关闭时进度显示「已接收 0 字」 | 录屏检查 | 显示「等待模型首个响应」 |

## 4. 上线阶段发现并修复的缺陷

| 缺陷 | 发现方式 | 修复与回归测试 |
|---|---|---|
| 合规过滤误删正常的拒绝说明与信息缺口说明 | 公网验收试运行（真实 DeepSeek 输出） | 拒绝语境识别（子句级、引号复述中和、转折后独立判断）；目标价须给出具体值才算违规。测试：拒绝 7 条保留、事实 3 条保留、伪装违规 13 条删除 |
| 公网无成本与滥用保护 | 上线要求 | 限流 / 并发 / 每日预算 / 请求体上限 / 调用预算上限；`tests/unit/rate-limit.test.ts`（10 项）、E2E 429 提示 |
| Vercel `hkg1` 无法连接扶摇 | 公网冒烟 + 临时诊断 | 函数区域改为 `sin1` |
| 多实例下 A/B 被误判「不一致」 | 公网 UI 验收 | 收盘事实标签不含获取时刻；`fuyao-provider.test.ts` 新增用例 |
| `sin1` 下扶摇连通性取决于实例出口 IP | 公网采样（同一部署 6 / 6 → 0 / 6） | Cloudflare Worker 中转；`tests/unit/relay-worker.test.ts`（6 项）与客户端「Secret 只发中转」用例 |
